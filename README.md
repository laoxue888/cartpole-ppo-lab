## 每篇可独立运行的代码

代码集中在 [code 文件夹说明](code/README.md)：五个 Python 文件与五篇博客一一对应，每个文件自带环境、网络、训练、评估和动画，没有项目内部依赖。可单独复制运行；附带五个可选的原实验模型，支持直接评估，也支持第四、五篇显式加载前篇模型微调。

各篇开头已经加入自己的代码链接和运行命令。从零运行不要求前一篇的模型；要复现原微调结果则使用 `--initial`。

## “继承”指什么

前两次切换（离散到连续、连续存活奖励到平滑奖励）在现有代码中是重新训练，文章继承的是模型、动作和算法设计，不能写成已加载上一模型继续微调。第四篇从第三篇的连续平滑模型加载参数，第五篇从第四篇位置模型加载参数；两次微调重新初始化 Adam 动量。

第一篇是完整基线；第二、三篇刻意把动作空间与奖励分开。第三篇如实说明平滑奖励并未改善每一项指标，不能因为章节名叫“优化”就将设计意图写成已证实的性能提升。第四、五篇围绕单一新目标有配套训练和模型选择调整，因此不属于只改一个参数的严格因果消融。
